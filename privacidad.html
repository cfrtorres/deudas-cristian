Política de privacidad

Deudas Cristian · Última actualización: 9 de noviembre de 2026

Deudas Cristian es una aplicación personal de control de deudas y gastos, creada y usada por Cristian Torres (Quito, Ecuador). No es un servicio abierto al público: la usa únicamente su desarrollador sobre su propia cuenta de Google.

1. Qué datos usa la aplicación

  • Correos de Gmail (solo lectura). Con el permiso gmail.readonly, la aplicación lee únicamente los correos de los bancos y entidades financieras que el propio usuario configura (por ejemplo, avisos de consumo, pago y vencimiento).
  • Datos extraídos. De cada correo se guarda solo lo necesario: tipo de aviso, monto, fecha, comercio o referencia y los últimos 4 dígitos de la cuenta o tarjeta. El cuerpo del correo no se guarda. No se almacenan cédulas, claves, números completos de cuentas ni datos de terceros.
  • Datos que el usuario ingresa. Gastos, categorías, presupuestos, pagos registrados y ajustes.

2. Para qué se usan

Exclusivamente para mostrar al usuario el estado de sus deudas, calendario de pagos, gastos, alertas e informes dentro de la aplicación. Los datos no se usan para publicidad, perfilado ni ningún otro fin.

3. Dónde se guardan

  • Los datos extraídos y los registros del usuario se guardan en una base de datos privada (Supabase) protegida con autenticación y reglas de acceso por fila: solo el usuario autenticado puede leerlos o modificarlos.
  • El permiso de acceso a Gmail (token) se guarda cifrado en el equipo del usuario y no se envía a ningún tercero.

4. Con quién se comparten

Con nadie. No se venden, alquilan ni transfieren datos de usuario a terceros, ni siquiera de forma agregada. Los proveedores de infraestructura (Google para la API de Gmail y Supabase para la base de datos) procesan los datos únicamente para prestar el servicio.

5. Uso limitado de datos de Google

El uso que hace Deudas Cristian de la información recibida de las APIs de Google y su transferencia a cualquier otra aplicación se ajusta a la Política de datos del usuario de los servicios de las APIs de Google, incluidos los requisitos de uso limitado. En concreto:

  • Los datos de Gmail se usan solo para ofrecer las funciones visibles en la aplicación descritas arriba.
  • No se transfieren a terceros, salvo lo necesario para prestar el servicio, cumplir la ley o con el consentimiento del usuario.
  • No se usan para publicidad ni se venden.
  • Ninguna persona lee los correos, salvo el propio usuario, con su consentimiento expreso, por motivos de seguridad o por exigencia legal.

6. Conservación y eliminación

  • Los datos se conservan mientras el usuario use la aplicación.
  • El usuario puede revocar el acceso a Gmail en cualquier momento desde Ajustes → «Desconectar» en la aplicación, o en myaccount.google.com/permissions. Al desconectar se borra el token guardado.
  • Para eliminar los datos guardados basta con vaciar las tablas de la base de datos o escribir al contacto indicado abajo.

7. Seguridad

Acceso solo con sesión autenticada, reglas de seguridad por fila, token de Gmail cifrado y claves guardadas fuera del código fuente.

8. Cambios

Si esta política cambia, se actualizará esta página con una nueva fecha.
